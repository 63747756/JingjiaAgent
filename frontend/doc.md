# 景嘉微AI助手 Web 使用说明

从本机部署地址进入用户或管理员登录页。普通用户使用任务对话、项目、文件、终端、预览和设置；管理员沿用团队成员、模型、宿主机、会话和审计页面。

任务在远程服务器沙箱中运行。文件和预览按环境授权，多个任务复用环境时遵循既有行为。Skills、规则、插件与 MCP 继续使用原授权范围。

未配置自有服务的帮助、社区、销售和升级入口隐藏。GitHub App 需独立注册并配置；原商业许可和自动 PR/MR 评审不在本期接入范围。

构建和部署见 ../runtime/jingjiaagent/README.md。原前端说明保存在 ../docs/upstream-records/frontend-guide.original.md。
