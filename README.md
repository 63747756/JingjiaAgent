# JingjiaAgent · 景嘉微AI助手

![JingjiaAgent](frontend/public/jingjiaagent-logo-blue.svg)

JingjiaAgent 是面向企业团队的 AI 任务工作台，支持在自有环境中部署。用户通过自然语言描述需求、提供参考资料，由 AI 在独立工作空间中调用工具、处理文件并生成可预览、可下载的成果，覆盖文档编写、数据分析、演示制作、网页操作和研发辅助等场景。

管理员可以集中配置模型、助手、技能和运行资源；员工通过浏览器提交任务、跟进执行过程、继续修改结果，并在项目中管理资料与成果。

## 主要功能

| 功能 | 说明 |
| --- | --- |
| 对话式任务执行 | 使用自然语言提出要求，结合附件和项目资料开展任务，查看执行过程，支持追问、补充要求和停止任务。 |
| 办公文档与数据处理 | 生成和修改 Word、Excel、PowerPoint 等文件，提取 PDF 内容，完成数据整理、计算与图表制作。 |
| 项目与成果管理 | 按项目组织任务和资料，集中查看、预览、下载成果，并保留成果的历史版本。 |
| 自定义 AI 助手 | 为不同工作场景配置助手指令、默认模型和可用技能，复用常用的处理方法与交付要求。 |
| 技能与工具接入 | 管理和使用技能包，对接 SkillHub，通过 MCP 接入外部工具与业务服务。 |
| 网页与研发辅助 | 支持浏览器操作、网页截图、代码编辑、终端命令、Git 操作和网页预览。 |
| 团队与运行管理 | 提供成员、角色和部门管理，支持配置 AD 域登录或 OIDC 登录，管理任务执行节点、资源及休眠回收策略。 |

## 典型场景

- **整理业务材料**：结合参考文档生成工作总结、项目报告、操作说明等文件，并根据反馈继续修订。
- **分析表格数据**：整理数据口径、计算统计指标、制作图表，输出可继续编辑的分析表格。
- **制作演示材料**：根据已有资料组织内容，生成可编辑的演示文稿。
- **处理网页与研发任务**：读取和操作网页、检查页面效果，完成代码修改、脚本编写和运行验证。

## 使用流程

1. 管理员配置模型服务、运行节点及团队可用的助手和技能。
2. 用户选择助手，描述任务要求，上传附件或引用项目资料。
3. AI 在任务工作空间中执行操作，用户可以查看进度并补充要求。
4. 在成果中心预览和下载文件，继续对话完成修改，或将任务归入项目持续管理。

## 部署与运行

支持 Linux amd64 环境下的在线和离线安装，可在单机部署，也可将控制台与任务执行节点分开部署。员工通过浏览器访问，无需在个人电脑安装任务执行环境。

发行包包含平台服务、任务运行镜像和安装器，目标主机无需检出源码或安装 Go、Node.js、Python 开发工具链。模型服务由部署方配置；完全内网使用时，需要准备内网可访问的模型及相关业务服务。

安装、升级、备份恢复、访问地址和证书配置请参阅 [在线／离线安装指南](installer/README.md)。
