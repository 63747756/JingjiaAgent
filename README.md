# JingjiaAgent · 景嘉微AI助手

基于 MonkeyCode fork 的远程 Agent 工作台，复用现有 Web、团队权限、任务对话、文件、终端、预览、Git、Skills、规则、插件和 MCP。执行后端使用自行部署的 agent-compose；手机 App、桌面客户端、本地 Agent 和浏览器扩展已退出交付。

![JingjiaAgent](frontend/public/jingjiaagent-logo-blue.svg)

本次产品更名从全新环境开始，不迁移旧账号、任务或文件。自有镜像修订号从 p1 开始，各组件独立递增。构建和本机部署见 [运行目录说明](runtime/jingjiaagent/README.md)，标识及允许保留的上游名称见 [名称映射](docs/rebrand/name-mapping.md)。

自动 PR/MR 评审暂不接入；monkeyai 保持独立。本机测试不代表独立 Linux、多节点或正式部署已验收。

上游项目：[MonkeyCode](https://github.com/chaitin/MonkeyCode)、[agent-compose](https://github.com/chaitin/agent-compose)。许可证与第三方版权声明保持原状，见 [LICENSE](LICENSE)。原介绍与历史验收记录保存在 docs 中。
