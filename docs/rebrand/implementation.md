# JingjiaAgent 更名实施记录

基线：`main b580f240`。实施分支：`codex/jingjiaagent-rebrand`。

## 本次修改

- 产品显示统一为 JingjiaAgent／景嘉微AI助手，导航采用提供的透明蓝色／白色 Logo，favicon 采用蓝底白标识。
- 首页保留原有结构，替换当前能力介绍及实际新环境截图；删除上游统计、宣传、销售及未配置的应用入口。
- 自有模块、环境变量、Cookie、Redis、数据库、存储桶、Compose、Guest 辅助组件和协议标识统一为 jingjiaagent；读写方及测试成对修改。
- Ent、Swagger 和前端客户端重新生成。保留现有业务 API、第三方 CLI／协议、许可证及上游来源；monkeyai 未参与改造。
- 四类自有镜像沿用独立 pN 修订号，首版均为 p1，修订号来自同一源码锁定文件。所有既有运行补丁及修复随源码保留。
- 镜像、节点、安装清单校验组件修订号及源码身份；daemon 与 Guest 可采用不同修订号。CI 默认只检查和构建，发布要求手动触发。
- 不提供旧名称别名或旧数据迁移。新安装使用独立数据卷、随机账号和密钥；归档只包含镜像及公开部署材料。

## 已进行的验证

本机 Docker Desktop 的 Linux 容器模式下，以真实模型验证 OpenCode、Codex、Claude 执行，问题回答、审批允许／拒绝、取消及恢复、模型切换、中文／二进制／空文件、PTY 重连、HTTP／WebSocket 预览、真实 MCP 工具调用、两用户权限及沙箱网络隔离。强制重启后端时，原 Run 完成且工具仅执行一次；沙箱停止并恢复后文件及原生会话保留。

源码检查：Linux CGO Go 全量测试通过；前端 364 项通过；部署安全契约 27 项、桥接契约 16 项及 Guest 两组共 10 项通过。浏览器检查首页、登录、用户和管理员界面及邮件预览，未发现旧统计请求和页面错误。

这些记录不将模拟契约当作真实运行验收，也不代表自然闲置计时、独立 Linux、多节点或正式多用户环境已验收。最终镜像重建、归档复载及空卷安装的结果另写入验收报告。
