## 收尾中发现并修复的问题

- 默认路由回退为 Taskflow 时，已有 compose 环境仍需 Git 凭证桥。按保留的节点配置
  注册该入口，继续校验任务、用户、VM、协议、仓库和当前项目授权。
- Git helper 同时包含空重置项与任务 helper；后续追问使用单值覆盖会失败。改为
  `--replace-all` 后添加唯一任务 helper，实际 Git 三次重复配置回归通过。
  原未提交命令在修复后完成对账，没有新建重复用户请求或重放已执行 Run。
- 已有运行修复继续保留：原 CPU/内存传递、容量拒绝补偿、三种 CLI 模型凭证恢复、
  daemon 中断清理、实时环境状态、休眠终端连接，以及后端恢复时重建 Web 网络代理。
