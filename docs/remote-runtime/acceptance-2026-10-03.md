## 本轮通过的场景

| 场景 | 实际证据与结果 |
| --- | --- |
| 个人 MCP | 原页面添加 HTTP 服务、携带鉴权头同步；实际 OpenCode 调用计算工具并返回私有随机回执。关闭工具后列表/执行均拒绝，成功记录仍为 1 |
| 团队 MCP | 原团队管理页添加服务并绑定默认分组，实际调用返回回执。改绑不包含原用户的测试分组后，原任务列表/执行拒绝，成功记录仍为 1 |
| 原页面创建成员 | runtime-member@example.invalid 来自原“添加成员”流程；初始密码仅在响应显示，刷新成员/默认分组各包含该账号一次；原 API 和原 Web 登录成功 |
| 成员任务 | 新成员通过原页面选择既有团队模型、节点及镜像，启动独立远程任务，实际模型返回 WEB_MEMBER_READY |
| 成员创建拒绝 | 重复邮箱拒绝且密码哈希不变；超额批量整体拒绝；外团队分组拒绝；普通用户 cookie 无权创建成员；拒绝请求未增加账号 |
| 分组管理边界 | 原管理员身份读取、改名、调整成员、删除外团队分组，以及更新外团队账号，均被原不可见错误拒绝；外团队夹具无变化 |
| 分组成员替换 | 原页面将新成员加入测试分组后，真实 Agent 调用团队工具。取消勾选保存后分组为空，原任务回复 WEB_MEMBER_MCP_REVOKED；列表/执行拒绝，成功调用仍为 1 |
| 两个有效任务凭证 | 两个账号、Sandbox、任务凭证互不相同；两个凭证都能通过原网关认证；团队工具按分组列表/执行；个人工具启用时，仅所有者任务可见，另一个有效任务不能列出或执行 |
| 同团队业务隔离 | 两个普通成员相互读取对方任务、历史、环境、终端和文件列表，均得到明确访问拒绝 |
| 审计 | 新成员初始密码未进入审计记录；保留操作结果、邮箱和成员信息；单元测试另覆盖管理员/密码重置响应及异常响应脱敏 |
| Git 协作任务 | 原认证 API 创建项目并添加真实成员；成员任务使用项目所有者的 Git 身份，真实 HTTP Git 服务认证克隆，OpenCode 读取中文文件并返回私有回执；原页面显示结果，刷新后历史保留 |
| Git 字节与提交 | HEAD 等于夹具原提交；中文文件 42 B 与原 Git blob 字节及 SHA256 一致，仓库无修改，origin URL 保留且不含凭证 |
| Git 凭证边界 | 两个账号分别创建任务、独立环境和项目时，直接使用对方身份均返回不可见错误；拒绝后任务/环境/项目/关联/模型凭证/命令行数均无增加 |
| Git 授权撤销 | 原项目 API 撤销协作者后，项目列表不可见，原内部凭证回调不返回密码；恢复后回调正常。缓存命中及已软删除成员不绕过校验 |

MCP 随机回执未提供在用户提示词中，实际工具执行同时由本机服务审计、原业务
mcp_tool_calls 和原任务历史验证；不以模型文本或模拟 RPC 单独证明调用成功。
验收结束保留个人工具关闭、测试团队分组为空的状态，已恢复原测试账号的浏览器会话。

- 运行适配器支持可选的 runtime.mcp_url，仅转换内置 HTTP 网关。接收任务时固定地址
  并加密持久化；正常部署使用 HTTPS，实验模式额外允许 Docker 主机地址。
- 独立开源启动入口注册默认 MemberManager，保留已有显式注入实现及原账号角色。
  PostgreSQL 事务、团队行锁与邮箱锁保护批量、成员上限及并发重复请求。
- 原分组接口校验所属团队，替换成员列表由事务完成。外团队/已删除用户不能加入分组。
- 初始密码和密码重置响应在原审计层脱敏。保留实际密码登录行为。
- 新附件输入和历史响应不暴露内部签名下载地址，新增不同 S3 URL 布局的契约检查。
- Git 身份在获取缓存凭证前校验用户归属，项目创建事务校验身份；已授权的项目协作者
  使用项目所有者身份。修正项目查询中协作者软删除过滤，原回调校验实际任务用户。
  任务创建日志不再输出 Git 凭证。
